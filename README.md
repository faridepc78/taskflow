# TaskFlow

TaskFlow is a Django-based project and task management application built as a practical learning project.

## Tech Stack

- Python 3.13
- Django 6.1
- MySQL 8.4
- Redis / Memurai
- Celery
- Bootstrap
- Mailtrap
- Ruff

## Current Features

- Registration with email OTP verification
- Login / Logout
- Forgot and reset password with OTP
- Change password
- User profiles
- Project CRUD
- Task CRUD
- Task status and priority
- Categories
- Search, filtering, and ordering
